# Seizure Early-Warning Signals

Final project for Math 472/572: Mathematical and Computational Neuroscience.

Some seizures are preceded by measurable warning signs and others aren't. This project uses bifurcation analysis of the Epileptor model to explain why, then turns the theory into features for a machine learning model that predicts seizures from EEG.

## Plan

- Analyze the Epileptor's saddle-node bifurcation and derive early-warning indicators (variance, autocorrelation, spectral reddening)
- Simulate drift-driven vs. noise-driven seizure onsets to validate the pipeline
- Train a classifier on real EEG and compare warning signals across seizure onset types
